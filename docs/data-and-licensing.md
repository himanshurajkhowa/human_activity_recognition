# Data access and licensing

RealWorld HAR provides recordings from 15 participants at seven body locations. The University of Mannheim hosts the recordings and asks users to cite the accompanying PerCom paper. The redistribution terms for RealWorld recordings and derived sensor samples remain unresolved. [RealWorld HAR](https://www.uni-mannheim.de/dws/research/projects/activity-recognition/dataset/dataset-realworld/) · [Sztyler and Stuckenschmidt, PerCom 2016](https://doi.org/10.1109/PERCOM.2016.7456521)

The earlier UCI HAPT dataset has a CC BY 4.0 license on its official page. Its recordings are available separately. [UCI HAPT](https://doi.org/10.24432/C54G7M)

This release contains Python source and aggregate results. The example generates its own sensor signals. Exact historical replay needs the original fitted model states, split and row records, and the prepared data bank. The public examples run with generated inputs or the included aggregate counts.
