# Data access and licensing

RealWorld HAR provides recordings from 15 participants at seven body locations. Get the dataset from the University of Mannheim and cite the accompanying PerCom paper. The dataset page provides downloads and a citation request. The redistribution terms for RealWorld recordings and derived sensor samples remain unresolved. [RealWorld HAR](https://www.uni-mannheim.de/dws/research/projects/activity-recognition/dataset/dataset-realworld/) · [Sztyler and Stuckenschmidt, PerCom 2016](https://doi.org/10.1109/PERCOM.2016.7456521)

The earlier UCI HAPT dataset has a CC BY 4.0 license on its official page. Its recordings are available separately. [UCI HAPT](https://doi.org/10.24432/C54G7M)

This release contains Python source and aggregate results. The example generates its own sensor signals. Exact historical replay needs the original fitted model states, split and row records, and the prepared data bank. The public dataset download alone does not provide those records. The example runs without any of them.

The software license for this source release is pending an owner decision. The dependencies are installed separately and retain their own licenses. Dataset permissions are separate from any future license for the project code.
